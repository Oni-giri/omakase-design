# Logos

These are Holdout's logos, the first app built with Omakase. Omakase itself has no logo: its name is set in Inter bold.

- `holdout-mark.svg`: the app mark. An ink rounded square holding a white outlined box split in two, the lower half filled with `bloom-sky`: the hidden half of the tests. Use at 30px in the sidebar.
- `holdout-lockup.svg`: mark plus the name in Inter semibold, ink. For headers and docs.

For another project built on this system, keep the same construction (ink square, white line drawing, one bloom colour) and swap the inner drawing.
