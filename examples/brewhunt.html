ripgrep

Search tool like grep and The Silver Searcher, recursive and fast, that respects your .gitignore.

searchrustdeveloper tools Formula · 14.1.1 · MIT · updated 3 days ago

What it does

ripgrep recursively searches the current directory for a regex pattern. By default it respects .gitignore and skips hidden files, binary files and directories you would not want to search.

rg "fn main" --type rust
rg -i todo src/ --glob '!*.test.ts'

Why people install it

It is usually much faster than grep -r on real repositories, with sensible defaults and good Unicode support. Editors such as VS Code use it under the hood for search.

Install
$brew install ripgrep
