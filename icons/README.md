# Icons

Single-weight stroke icons on a 16px grid (role glyphs on 14px), 1.5px stroke, round caps and joins. Ink is `#18181B` (`ink`); role glyphs use their role colour. Shown at 16px in navigation, 14px inline.

- `issues.svg`: Issues page.
- `board.svg`: Board page.
- `milestone.svg`: Milestones.
- `access.svg`: Access and log (a key).
- `pipeline.svg`: CI pipeline.
- `search.svg`: search and command palette trigger.
- `filter.svg`: filter button and saved views.
- `lock.svg`: sealed items in redacted lists.
- `shield-check.svg`: verdict box.
- `role-author.svg`: author (pen, `role-author`).
- `role-implementer.svg`: implementer (brackets, `role-implementer`).
- `role-reviewer.svg`: reviewer (eye, `role-reviewer`).
